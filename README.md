#Taller portafolio de Harold Aciniegas

En este repocitorio se manejara la creacion de ramas,
manejo de codigo en html y css para la creacion de un portafolio personal

##caracteristicas
-  Diseño visual moderno con estilo oscuro (dark mode).
- Secciones organizadas: inicio, sobre mí, habilidades, proyectos y contacto.
- Menú de navegación interactivo con desplazamiento suave.
- Formulario de contacto funcional.
- Integración de un enlace visual a un video o presentación personal.
- Interfaz adaptable a diferentes tamaños de pantalla (responsive design)

---
## tecnologia 
- Lenguaje principal: HTML5, CSS3 y JavaScript.
- Frameworks: No se utilizan frameworks externos, se trabaja con tecnologías nativas.
- Librerías: Iconos SVG y efectos visuales mediante CSS.
- Herramientas de desarrollo: Visual Studio Code y navegador web moderno.
